## 개요
주식에 대해 어느정도는 알아야, 유의미한 데이터를 구분할 능력이 생길 것 같다.

진짜 상세한 내용이 필요하면 주변에 물어볼 것 같은데, 뭘 모르는지는 아는 수준이 되어야 질문할 수 있기도 하다

## 용어
### 한국 거래소 KRX
> 한국의 유일한 종합 증권 거래소.

### 지수
> 특정 시장이나 경제 상황의 변동 추이를 종합적으로 보여주는 지표.
> - 주식 지수 : 특정 기준에 따라 묶은 여러 주식의 가격 변동을 하나의 숫자로 나타낸 것.
> - 채권 지수 : 다양한 채권의 가격이나 수익률 변동을 종합적으로 나타내는 지표
> - 경제 지수 :  물가, 실업률, GDP 성장률 등. 경제 전반의 상황

### 주식
> 회사가 사업 자금을 마련하기 위해 발행하는 일종의 증서.
> 
> 주식을 산다는 것은 그 회사의 일부를 소유하는 것.
> 
> 한국 주식 종류
> - 코스피: 대기업 중심의 주식시장.
> - 코스닥: 중소기업 및 벤처기업 중심의 주식시장.
> - 코넥스: 초기 중소기업 및 벤처기업 전용 주식시장. 전문 투자자 중심의 시장.


## OHLCV
- **O (Open): 시가** - 해당 기간의 **최초 거래 가격**입니다. 예를 들어, 일봉 차트라면 그날 장이 시작했을 때의 가격입니다.
- **H (High): 고가** - 해당 기간 동안 기록된 **최고 가격**입니다.
- **L (Low): 저가** - 해당 기간 동안 기록된 **최저 가격**입니다.
- **C (Close): 종가** - 해당 기간의 **마지막 거래 가격**입니다. 일봉 차트라면 그날 장이 마감했을 때의 가격입니다.
- **V (Volume): 거래량** - 해당 기간 동안 거래된 **총 수량**입니다. 주식 수나 계약 수 등으로 표시됩니다.

알파벳의 순서는 가격이 매겨지는 시간에 따라 작성한 듯 하다. 시가 <-> 종가 / 고가 <-> 저가의 느낌이다.

## 로직 적용 방안
일단 뉴스의 키워드들을 엘라스틱 서치에 저장한다.

키워드들이 많이 발생한 기간을 먼저 선정해야한다. 하나의 키워드도, 많이 발생한 시기가 여럿 있을것이다.

우선은 매일경제를 크롤링하는 것으로 시작했지만, 여러 기사를 더 수집하는 것이 좋을 것 같다는 생각이 든다. 시기와 키워드의 연관성이 깊을수록 신빙성이 좋은 데이터가 될 것 같다.

예를 들면 엔비디아가 확 올랐다가, 딥시크 때 내려왔던 것처럼.

변동성 등, 키워드와 관련성이 높은 종목들을 뽑아주고, 보여주면 된다.

구체적인 예시는 아래와 같다.

```
(input)검색어 "구글" 입력
-> (find_articles)구글이라는 키워드가 많이 발생한 기사들을 찾는다.
-> (define_dates)어떤 기간에 많이 발생했는지를 구한다.
-> (find_stocks)발생한 때 변동성이 컸던 주식을 고른다.
-> (show_graph)해당 시기의 관련 주식들을 그래프로서 보여준다.
```

### 과제
- 어떤 언론사의 기사 데이터를 수집할것인가?
- **"키워드가 많이"** 발생한 것은 몇회인가?
- 기사 날짜들이 다 비슷할수도 있지만, 꽤 다를수도 있다. 어떻게 **"날짜를 일반화"**할까?
- **"변동성이 크다는 것"**은 어떻게 구분할것인가?
	- 특정 기간으로 잘라야 된다는 것은 자명해보인다. 짧든 길든.
		- 고정 기간으로 자른다. 기사 발생 -> n일 후 
		- 변동이 크지 않은때가 안정기라고 한다면, 안정기 -> 기사 발생 -> 안정기 일때의 차이로 자르기

### [증권사 API 활용]()
- **장점:** 실시간 주가 데이터를 포함한 다양한 금융 데이터를 비교적 안정적으로 가져올 수 있습니다. 주문 기능까지 제공하는 경우도 있습니다.
- **단점:** 증권사별로 API 제공 여부, 신청 절차, 사용 방법, 데이터 포맷 등이 다릅니다. 개발 경험이 필요하며, API 사용료가 발생할 수도 있습니다.
- **주요 증권사 API:** 키움증권 Open API+, 대신증권 CybosPlus, 삼성증권 OpenAPI 등
- **활용 방법:** 각 증권사의 API 문서를 참고하여 개발해야 합니다. 파이썬, C++, Java 등 다양한 언어를 지원합니다.

### [금융 데이터 제공 웹사이트 및 API 활용]()
- **장점:** 다양한 출처의 정제된 금융 데이터를 API 형태로 제공받을 수 있습니다. 재무 데이터, 기업 정보, 뉴스 데이터 등을 통합적으로 얻을 수 있는 경우도 있습니다.
- **단점:** 대부분 유료 서비스이며, 데이터 품질과 제공 범위가 서비스 제공업체마다 다를 수 있습니다.
- **주요 데이터 제공업체:** Refinitiv, Bloomberg, FactSet, Quandl 등 (국내 업체도 존재)
- **활용 방법:** 각 서비스 제공업체의 API 문서를 참고하여 연동해야 합니다.

### [공공 데이터 활용]()
- **장점:** 한국거래소(KRX) 데이터정보시스템 등 공공기관에서 제공하는 일부 주식 시장 데이터를 무료로 얻을 수 있습니다.
- **단점:** 제공되는 데이터의 종류나 형태가 제한적일 수 있으며, API 형태로 제공되지 않는 경우도 있어 데이터 가공에 추가적인 노력이 필요할 수 있습니다.
- **활용 방법:** 각 공공기관의 웹사이트를 통해 데이터 다운로드 또는 API 연동 방법을 확인해야 합니다.
